# Documentation Structure

This folder is organized to keep project references and course deliverables easy to find.

- `Project/`: core project planning and design artifacts.
- `Tasks/`: assignment-focused materials by task number.

For Task 1:

- `Documentation/Tasks/Task_1/Resources/`: instructor template, grading rubric, and source instructions.
- `Documentation/Tasks/Task_1/Submissions/`: report drafts, logs, and final submission files.
